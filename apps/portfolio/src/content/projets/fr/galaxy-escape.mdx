## Contexte

Un projet de jeu web : pousser le navigateur jusqu'à une expérience 3D fluide, avec seulement JavaScript et WebGL.

## Problème résolu

Créer une expérience de jeu immersive et fluide directement dans le navigateur, sans rien installer.

## Choix techniques

- **Three.js** pour le rendu WebGL.
- **Génération procédurale** des niveaux pour une course sans fin.
- **Boucle requestAnimationFrame optimisée** pour tenir 60 images par seconde.
- **Collisions et effets de particules** écrits à la main.
