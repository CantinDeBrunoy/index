## Contexte

Un projet backend de 2023, pour pratiquer les standards de l'écosystème .NET sur une base de code pensée pour durer.

## Problème résolu

Concevoir une API scalable, testable et maintenable en suivant les bonnes pratiques .NET.

## Choix techniques

- **Architecture propre** avec le patron Repository, découpée en microservices.
- **TDD avec xUnit** : les tests avant le code.
- **Entity Framework Core** sur SQL Server pour la persistance.
- **Swagger** pour la documentation et **Docker** pour l'exécution.
